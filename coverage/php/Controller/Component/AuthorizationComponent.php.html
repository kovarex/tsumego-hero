4 * Shim of CakePHP 5's AuthorizationComponent. The call site is identical:
5 * $this->Authorization->authorize('Admin') -> App\Policy\AdminPolicy::canAdminstats.
6 *
7 * Policies live in App\Policy and are resolved through composer (PSR-4), so a new
8 * policy file is picked up without regenerating the classmap.
9 *
10 * Resources can be:
11 * - a string (policy name, e.g. 'Admin') -> policy receives only the identity
12 * - an array in the wrapped Cake form, e.g. ['Set' => $row] -> policy is resolved
13 *   from the first key and receives the unwrapped row, e.g.
14 *   App\Policy\SetPolicy::canView($user, $row)
15 * - an object -> policy resolved from the class basename and the object is passed
16 *   as the second argument (no current caller, kept for parity with CakePHP 5)

18 * - Not logged in        -> UnauthorizedException (401)
